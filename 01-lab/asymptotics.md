# Расчёт асимптотики

Ниже для каждой сданной задачи: сколько времени занимает решение и сколько дополнительной памяти нужно, кроме самого входного массива. n — длина массива. Для матрицы n — число строк, m — число столбцов.

Один проход циклом по массиву — это O(n) по времени. Два вложенных цикла по всем парам элементов, как в простых сортировках, — это O(n^2).

## Задачи 1–10

| Задача | Время | Дополнительная память | Почему |
|--------|-------|------------------------|--------|
| 1. Минимум и максимум | O(n) | O(1) | Один проход, храню два числа |
| 2. Первый индекс | O(n) | O(1) | Иду слева направо и останавливаюсь, когда нашла число. В худшем случае смотрю весь массив |
| 3. Количество вхождений | O(n) | O(1) | Один проход и счётчик |
| 4. Все индексы | O(n) | O(n) | Два прохода. Память нужна под ответ: в худшем случае индексов столько же, сколько элементов |
| 5. Сумма на чётных местах | O(n) | O(1) | Иду с шагом 2, храню только сумму |
| 6. Больше среднего | O(n) | O(1) | Сначала сумма, потом ещё один проход для подсчёта |
| 7. Второй максимум | O(n) | O(1) | Один проход, храню два числа |
| 8. Плюс и минус | O(n) | O(n) | Два прохода. Новые массивы вместе не длиннее исходного |
| 9. Проверка порядка | O(n) | O(1) | Сравниваю соседей. Могу остановиться раньше, но в худшем случае смотрю все пары |
| 10. Последнее кратное | O(n) | O(1) | Иду с конца. В худшем случае до начала массива |

## Сортировки

| Задача | Время | Дополнительная память | Почему |
|--------|-------|------------------------|--------|
| 13. Выбором | O(n^2) | O(1) | Для каждой позиции ещё раз прохожу хвост массива. Меняю элементы местами, новый массив не создаю |
| 14. Вставками | O(n^2) в худшем случае, O(n) если массив уже стоит по убыванию | O(1) | Каждое число может сдвинуть все предыдущие. Если сдвигать нечего, получается один проход |
| 15. Пузырьком | O(n^2) в худшем случае, O(n) если массив уже отсортирован | O(1) | До n проходов, на каждом до n сравнений. Если обменов не было, выхожу сразу |
| 21. K-й минимум | O(n log n) | O(log n), в худшем случае до O(n) | Сначала сортировка, потом беру элемент с индексом k − 1 за O(1). `Arrays.sort` для `int[]` в JDK 14 и новее укладывается в O(n log n) даже в худшем случае. Память: стек быстрой сортировки занимает O(log n), а при слиянии уже упорядоченных участков JDK может взять временный массив до O(n) |

Задачи 13 и 14 сами требуют именно эти сортировки, поэтому квадрат тут ожидаемый, а не случайная ошибка.
