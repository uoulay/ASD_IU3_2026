## 1. Условие

Вход: квадратная матрица n x n.
Выход: сумма элементов на побочной диагонали
(от правого верхнего угла к левому нижнему).

Ввод:
n
дальше n строк по n чисел

## 2. Идея решения

Побочная диагональ идёт от правого верхнего угла к левому нижнему. В строке `row` её элемент стоит в столбце `n − 1 − row`, поэтому снова достаточно одного цикла по строкам. Для нечётного n диагонали пересекаются в центральном элементе, и он учитывается один раз в каждой сумме.

## 3. Алгоритм в коде

```java
public static long sumSideDiagonal(int[][] matrix) {
    long sum = 0;
    int lastColumn = matrix.length - 1;
    for (int row = 0; row < matrix.length; row++) {
        sum = sum + matrix[row][lastColumn - row];
    }
    return sum;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(1) |

**Обоснование.** Цикл делает n итераций по одному сложению, то есть O(n) относительно размера стороны. Память: `sum`, `lastColumn` и счётчик, O(1).
