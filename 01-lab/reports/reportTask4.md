## 1. Условие

Вход: массив из n целых чисел и число x.
Выход: все индексы элементов, равных x, в порядке возрастания.

Ввод:
n x
a1 a2 ... an

Вывод: индексы через пробел. Если числа нет, строка пустая.

## 2. Идея решения

Заранее неизвестно, сколько индексов получится, а готовые списки в этой работе не нужны. Поэтому делается два прохода: первый считает количество вхождений, второй создаёт массив нужной длины и записывает в него индексы по возрастанию. Так результат точного размера получается без списков и без копирования.

## 3. Алгоритм в коде

```java
public static int[] findAllIndexes(int[] numbers, int target) {
    int count = 0;
    for (int i = 0; i < numbers.length; i++) {
        if (numbers[i] == target) {
            count++;
        }
    }

    int[] indexes = new int[count];
    int position = 0;
    for (int i = 0; i < numbers.length; i++) {
        if (numbers[i] == target) {
            indexes[position] = i;
            position++;
        }
    }
    return indexes;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(n) |

**Обоснование.** Два последовательных цикла по n элементов дают 2n шагов, то есть O(n). Дополнительная память нужна под массив `indexes`: в худшем случае (все элементы равны `x`) в нём n чисел, поэтому O(n). Если вхождений нет, массив пустой.

## 5. Ручные тесты

Входные данные записаны в формате, который читает `main` (первая строка — размеры, далее элементы). Ожидаемые ответы получены вручную до запуска программы, затем сверены с её выводом.

| № | Ввод | Ожидаемый вывод | Что проверяет |
|--:|------|-----------------|---------------|
| 1 | `5 2`<br>`2 1 2 3 2` | `0 2 4` | три вхождения, порядок возрастания |
| 2 | `3 7`<br>`1 2 3` | (пустая строка) | вхождений нет, ответ — пустой массив |
| 3 | `3 4`<br>`4 4 4` | `0 1 2` | все элементы подходят, ответ длины n |
| 4 | `3 1`<br>`1 2 3` | `0` | единственное вхождение в начале |
| 5 | `3 3`<br>`1 2 3` | `2` | единственное вхождение в конце |
| 6 | `2 -1`<br>`-1 5` | `0` | отрицательное значение |

**Покрытие кода.** Тест 2 проверяет случай `count == 0` (второй цикл не записывает ничего), тест 3 — `if` истинен на каждой итерации обоих циклов. Каждая строка метода выполняется.
