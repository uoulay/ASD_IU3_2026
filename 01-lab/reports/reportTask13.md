## 1. Условие

Вход: массив из n целых чисел.
Выход: массив, отсортированный по неубыванию.
Сортировку нужно написать самому, без готовой функции сортировки.

Ввод:
n
a1 a2 ... an

Вывод: числа через пробел.

## 2. Идея решения

Внешний цикл по `i` разделяет массив на отсортированную часть слева и неотсортированную справа. На каждом шаге внутренним циклом ищется индекс минимального элемента в неотсортированной части, и этот элемент меняется местами с элементом на позиции `i`. После n − 1 шагов массив отсортирован по неубыванию. Сортировка пишется вручную, как требует условие.

## 3. Алгоритм в коде

```java
public static int[] sortAscending(int[] numbers) {
    for (int i = 0; i < numbers.length - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < numbers.length; j++) {
            if (numbers[j] < numbers[minIndex]) {
                minIndex = j;
            }
        }
        int temporary = numbers[i];
        numbers[i] = numbers[minIndex];
        numbers[minIndex] = temporary;
    }
    return numbers;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n²) |
| Дополнительная память | O(1) |

**Обоснование.** Внешний цикл делает n − 1 итераций, внутренний на шаге `i` делает n − 1 − i сравнений. Всего (n − 1) + (n − 2) + … + 1 = n(n − 1)/2 сравнений, то есть O(n²). Это число не зависит от входных данных, поэтому лучший случай тоже O(n²). Сортировка идёт на месте, из памяти нужны `minIndex`, `temporary` и счётчики: O(1).
