## 1. Условие

Вход: массив из n целых чисел и число x.
Выход: количество элементов, равных x.

Ввод:
n x
a1 a2 ... an

## 2. Идея решения

Один проход по массиву со счётчиком: каждый элемент, равный `x`, увеличивает счётчик на единицу. Ранний выход здесь невозможен, потому что надо посчитать все вхождения.

## 3. Алгоритм в коде

```java
public static int countMatches(int[] numbers, int target) {
    int count = 0;
    for (int i = 0; i < numbers.length; i++) {
        if (numbers[i] == target) {
            count++;
        }
    }
    return count;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(1) |

**Обоснование.** Цикл `for` всегда делает ровно n итераций, на каждой одно сравнение и, возможно, `count++`. Итого O(n). В памяти только переменные `count` и `i`, то есть O(1).

## 5. Ручные тесты

Входные данные записаны в формате, который читает `main` (первая строка — размеры, далее элементы). Ожидаемые ответы получены вручную до запуска программы, затем сверены с её выводом.

| № | Ввод | Ожидаемый вывод | Что проверяет |
|--:|------|-----------------|---------------|
| 1 | `5 2`<br>`2 1 2 3 2` | `3` | число встречается несколько раз, в начале, середине и конце |
| 2 | `3 7`<br>`1 2 3` | `0` | числа нет |
| 3 | `3 4`<br>`4 4 4` | `3` | все элементы равны x |
| 4 | `2 -1`<br>`-1 1` | `1` | отрицательное значение |
| 5 | `2 0`<br>`0 0` | `2` | ноль и минимальная длина |
| 6 | `4 3`<br>`3 1 1 3` | `2` | совпадения только по краям |

**Покрытие кода.** Тесты 2 и 3 дают ветки «`if` ни разу не сработал» и «сработал на каждом шаге». Остальные тесты чередуют обе ветки. Все строки метода выполняются.
