## 1. Условие

Вход: матрица n x m из целых чисел.
Выход: массив из n элементов — сумм строк.

Ввод:
n m
дальше n строк по m чисел

Вывод: суммы строк через пробел.

## 2. Идея решения

Для матрицы n × m двойным циклом считается сумма каждой строки: внешний цикл выбирает строку, внутренний складывает её элементы в `long`, затем сумма записывается в `sums[row]`. Матрица хранится как массив массивов `int[][]`, это естественное представление таблицы с доступом по двум индексам за O(1).

## 3. Алгоритм в коде

```java
public static long[] sumRows(int[][] matrix) {
    long[] sums = new long[matrix.length];
    for (int row = 0; row < matrix.length; row++) {
        long sum = 0;
        for (int column = 0; column < matrix[row].length; column++) {
            sum = sum + matrix[row][column];
        }
        sums[row] = sum;
    }
    return sums;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n · m) |
| Дополнительная память | O(n) |

**Обоснование.** Внешний цикл делает n итераций, внутренний — m, и каждая ячейка посещается ровно один раз, то есть n · m элементарных операций: O(n · m). Дополнительная память — массив `sums` из n элементов, O(n).
