## 1. Условие

Вход: массив из n целых чисел и число x.
Выход: массив, из которого удалены все вхождения x.

Ввод:
n x
a1 a2 ... an

Вывод: оставшиеся числа через пробел. Если ничего не осталось, строка пустая.

## 2. Идея решения

Удалять элементы из середины массива сдвигом дорого, да и длина массива в Java фиксирована. Поэтому делается два прохода: первый считает, сколько элементов не равны `x`, второй создаёт массив такой длины и копирует в него оставшиеся элементы в прежнем порядке.

## 3. Алгоритм в коде

```java
public static int[] removeValue(int[] numbers, int value) {
    int count = 0;
    for (int i = 0; i < numbers.length; i++) {
        if (numbers[i] != value) {
            count++;
        }
    }

    int[] result = new int[count];
    int position = 0;
    for (int i = 0; i < numbers.length; i++) {
        if (numbers[i] != value) {
            result[position] = numbers[i];
            position++;
        }
    }
    return result;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(n) |

**Обоснование.** Два последовательных цикла по n элементов, то есть O(n). Создаётся массив `result`, в худшем случае (значения `x` в массиве нет) он той же длины n, поэтому O(n).

## 5. Ручные тесты

Входные данные записаны в формате, который читает `main` (первая строка — размеры, далее элементы). Ожидаемые ответы получены вручную до запуска программы, затем сверены с её выводом.

| № | Ввод | Ожидаемый вывод | Что проверяет |
|--:|------|-----------------|---------------|
| 1 | `5 2`<br>`1 2 3 2 4` | `1 3 4` | удаляются все вхождения |
| 2 | `3 2`<br>`1 3 4` | `1 3 4` | значения нет, массив не меняется |
| 3 | `3 5`<br>`5 5 5` | (пустая строка) | удалены все элементы |
| 4 | `4 1`<br>`1 2 3 4` | `2 3 4` | удаляется первый элемент |
| 5 | `4 4`<br>`1 2 3 4` | `1 2 3` | удаляется последний элемент |
| 6 | `2 0`<br>`0 1` | `1` | удаляется ноль |
| 7 | `3 -1`<br>`-1 2 -1` | `2` | отрицательное значение |
| 8 | `2 3`<br>`3 3` | (пустая строка) | минимальная длина, всё удалено |

**Покрытие кода.** Условие `!= value` проходит в обе стороны в обоих циклах (тесты 1, 2, 3). Случай `count == 0` (пустой результат) — тесты 3 и 8.
