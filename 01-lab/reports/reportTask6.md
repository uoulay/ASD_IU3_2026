## 1. Условие

Вход: массив из n целых чисел.
Выход: количество элементов, строго больших среднего арифметического.
Среднее гарантированно целое.

Ввод:
n
a1 a2 ... an

## 2. Идея решения

Сначала первым проходом считается сумма элементов, из неё получается среднее арифметическое (по условию оно целое). Вторым проходом подсчитываются элементы, которые строго больше среднего. Сумма хранится в `long`, чтобы не переполниться.

## 3. Алгоритм в коде

```java
public static int countAboveAverage(int[] numbers) {
    long sum = 0;
    for (int i = 0; i < numbers.length; i++) {
        sum = sum + numbers[i];
    }

    long average = sum / numbers.length;
    int count = 0;
    for (int i = 0; i < numbers.length; i++) {
        if (numbers[i] > average) {
            count++;
        }
    }
    return count;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(1) |

**Обоснование.** Два последовательных цикла по n элементов, между ними одно деление за O(1). Итого 2n шагов, то есть O(n). Хранятся `sum`, `average`, `count` и счётчик цикла: O(1).

## 5. Ручные тесты

Входные данные записаны в формате, который читает `main` (первая строка — размеры, далее элементы). Ожидаемые ответы получены вручную до запуска программы, затем сверены с её выводом.

| № | Ввод | Ожидаемый вывод | Что проверяет |
|--:|------|-----------------|---------------|
| 1 | `4`<br>`1 2 3 6` | `1` | среднее 3, строго больше только 6 |
| 2 | `4`<br>`4 4 4 4` | `0` | все равны среднему, «строго больше» не выполняется |
| 3 | `2`<br>`1 3` | `1` | минимальная длина, среднее 2 |
| 4 | `3`<br>`-3 0 3` | `1` | среднее равно нулю, есть отрицательные числа |
| 5 | `5`<br>`1 2 3 4 5` | `2` | среднее 3, больше среднего 4 и 5 |
| 6 | `3`<br>`-5 -5 -5` | `0` | отрицательные одинаковые числа |
| 7 | `3`<br>`2147483647 2147483647 2147483647` | `0` | сумма 6442450941 не помещается в int, но среднее считается верно |
| 8 | `3`<br>`2147483647 2147483647 2147483644` | `2` | среднее 2147483646, больше него два элемента |

**Покрытие кода.** Тесты 1, 5, 8 дают обе ветки условия `numbers[i] > average` (истинно и ложно), тест 2 — случай, когда условие ложно всегда. Тесты 7 и 8 проверяют переполнение суммы.
