## 1. Условие

Вход: массив из n целых чисел и число k (k не равно 0).
Выход: индекс последнего элемента, кратного k. Если такого нет — -1.

Ввод:
n k
a1 a2 ... an

## 2. Идея решения

Нужен последний подходящий элемент, поэтому массив просматривается справа налево, и первый найденный по этому пути элемент, кратный `k`, как раз последний в массиве. Он возвращается сразу. Если подходящих нет, возвращается `-1`. Проверка кратности делается через остаток `% divisor == 0`; она верна и для отрицательных чисел и нуля.

## 3. Алгоритм в коде

```java
public static int findLastDivisibleIndex(int[] numbers, int divisor) {
    for (int i = numbers.length - 1; i >= 0; i--) {
        if (numbers[i] % divisor == 0) {
            return i;
        }
    }
    return -1;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(1) |

**Обоснование.** Цикл `for (int i = numbers.length - 1; i >= 0; i--)` в худшем случае (кратного нет или он единственный в начале) делает n итераций по O(1), то есть O(n). Память: счётчик и параметры, O(1).
