## 1. Условие

Вход: массив из n целых чисел.
Выход: массив той же длины, где i-й элемент равен сумме первых i + 1 элементов.

Ввод:
n
a1 a2 ... an

Вывод: числа через пробел.

## 2. Идея решения

Каждый элемент результата — сумма первых i + 1 чисел. Пересчитывать её заново каждый раз не нужно: `totals[i] = totals[i - 1] + numbers[i]`. Первый элемент копируется из исходного массива (по условию n > 1, поэтому `numbers[0]` существует). Результат хранится в массиве `long[]`, потому что сумма может выйти за пределы `int`.

## 3. Алгоритм в коде

```java
public static long[] runningTotal(int[] numbers) {
    long[] totals = new long[numbers.length];
    totals[0] = numbers[0];
    for (int i = 1; i < numbers.length; i++) {
        totals[i] = totals[i - 1] + numbers[i];
    }
    return totals;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(n) |

**Обоснование.** Цикл `for` от 1 до n − 1 делает n − 1 шаг по одному сложению, это O(n). Результат `totals` содержит n элементов, поэтому дополнительная память O(n); она необходима, так как ответ сам состоит из n чисел.
