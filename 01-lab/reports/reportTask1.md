## 1. Условие

Вход: массив из n целых чисел.
Выход: минимальный и максимальный элементы массива.

Ввод:
n
a1 a2 ... an

Вывод: минимум и максимум через пробел.

## 2. Идея решения

Минимум и максимум ищутся за один проход. Первый элемент берётся как начальное значение и для минимума, и для максимума, затем каждый следующий элемент сравнивается с обоими текущими значениями. Сортировка не нужна: она дороже и не даёт выигрыша. Данные хранятся в обычном массиве `int[]`, а результат возвращается массивом из двух чисел.

## 3. Алгоритм в коде

```java
public static int[] findMinAndMax(int[] numbers) {
    int minimum = numbers[0];
    int maximum = numbers[0];

    for (int i = 1; i < numbers.length; i++) {
        if (numbers[i] < minimum) {
            minimum = numbers[i];
        }
        if (numbers[i] > maximum) {
            maximum = numbers[i];
        }
    }

    return new int[] {minimum, maximum};
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(1) |

**Обоснование.** Цикл `for (int i = 1; i < numbers.length; i++)` выполняется n − 1 раз, в теле два сравнения и до двух присваиваний, то есть O(1) на итерацию. Итого O(n). Из памяти используются две переменные `minimum` и `maximum` и массив из двух элементов для ответа, размер не зависит от n, поэтому O(1).

## 5. Ручные тесты

Входные данные записаны в формате, который читает `main` (первая строка — размеры, далее элементы). Ожидаемые ответы получены вручную до запуска программы, затем сверены с её выводом.

| № | Ввод | Ожидаемый вывод | Что проверяет |
|--:|------|-----------------|---------------|
| 1 | `4`<br>`5 1 7 2` | `1 7` | минимум и максимум стоят не по краям массива |
| 2 | `2`<br>`3 9` | `3 9` | возрастающая пара: срабатывает только обновление максимума |
| 3 | `2`<br>`9 3` | `3 9` | убывающая пара: срабатывает только обновление минимума |
| 4 | `3`<br>`4 4 4` | `4 4` | все равны: ни одно из условий не выполняется |
| 5 | `3`<br>`-5 -1 -9` | `-9 -1` | только отрицательные числа |
| 6 | `2`<br>`-2147483648 2147483647` | `-2147483648 2147483647` | крайние значения типа int |
| 7 | `4`<br>`0 -3 3 0` | `-3 3` | ноль в середине диапазона |

**Покрытие кода.** Тесты 2 и 3 по отдельности проходят обе ветки `if` (условие истинно / ложно), тест 4 — случай, когда оба условия ложны, тест 1 — оба условия истинны на разных элементах. Выполняется каждая строка метода и `main`.
