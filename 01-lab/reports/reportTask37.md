## 1. Условие

Вход: массив из n целых чисел.
Выход: массив, записанный в обратном порядке.
Разворот делается на месте, новый массив не создаётся.

Ввод:
n
a1 a2 ... an

Вывод: числа через пробел.

## 2. Идея решения

Разворот делается на месте двумя указателями: `left` идёт с начала, `right` с конца, на каждом шаге элементы меняются местами, указатели сдвигаются к середине. Цикл заканчивается, когда они встречаются. Для нечётной длины средний элемент остаётся на месте. Новый массив не создаётся, как и требует условие.

## 3. Алгоритм в коде

```java
public static int[] reverse(int[] numbers) {
    int left = 0;
    int right = numbers.length - 1;
    while (left < right) {
        int temporary = numbers[left];
        numbers[left] = numbers[right];
        numbers[right] = temporary;
        left++;
        right--;
    }
    return numbers;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(1) |

**Обоснование.** Цикл `while (left < right)` делает ⌊n/2⌋ итераций по O(1), то есть O(n). Память: `left`, `right`, `temporary`, O(1), так как массив меняется на месте.
