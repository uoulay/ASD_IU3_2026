## 1. Условие

Вход: массив из n целых чисел.
Выход: YES, если массив неубывающий, иначе NO.

Ввод:
n
a1 a2 ... an

## 2. Идея решения

Массив неубывающий, если каждый элемент не меньше предыдущего. Цикл сравнивает соседние пары, при первом нарушении сразу возвращается `false`, остальные элементы можно не смотреть. Если цикл прошёл до конца, возвращается `true`. Равные соседи нарушением не считаются.

## 3. Алгоритм в коде

```java
public static boolean isNonDecreasing(int[] numbers) {
    for (int i = 1; i < numbers.length; i++) {
        if (numbers[i] < numbers[i - 1]) {
            return false;
        }
    }
    return true;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(1) |

**Обоснование.** В худшем случае (массив отсортирован или нарушение в самом конце) цикл делает n − 1 сравнение, это O(n). Память: только счётчик цикла, O(1).

## 5. Ручные тесты

Входные данные записаны в формате, который читает `main` (первая строка — размеры, далее элементы). Ожидаемые ответы получены вручную до запуска программы, затем сверены с её выводом.

| № | Ввод | Ожидаемый вывод | Что проверяет |
|--:|------|-----------------|---------------|
| 1 | `4`<br>`1 2 2 3` | `YES` | равные соседи допустимы |
| 2 | `3`<br>`1 3 2` | `NO` | нарушение в середине |
| 3 | `2`<br>`5 5` | `YES` | минимальная длина, равные элементы |

| 5 | `4`<br>`4 3 2 1` | `NO` | массив убывает, нарушение сразу |
| 6 | `4`<br>`1 2 3 1` | `NO` | нарушение только на последней паре |
| 7 | `3`<br>`-3 -1 0` | `YES` | отрицательные числа по возрастанию |
| 8 | `4`<br>`1 2 3 4` | `YES` | строго возрастающий массив |

**Покрытие кода.** Тесты 2, 4, 5, 6 доходят до `return false` внутри цикла, тесты 1, 3, 7, 8 завершают цикл и возвращают `true`. В `main` покрыты обе ветки `if` / `else` (`YES` и `NO`).
