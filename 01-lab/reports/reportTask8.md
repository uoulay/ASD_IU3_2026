## 1. Условие

Вход: массив из n целых чисел.
Выход: два массива — положительные и отрицательные, в исходном порядке.
Нули не входят ни в один.

Ввод:
n
a1 a2 ... an

Вывод: первая строка — положительные, вторая — отрицательные.

## 2. Идея решения

Размер результата заранее неизвестен, поэтому первый проход считает положительные и отрицательные числа, а второй создаёт два массива нужной длины и заполняет их в исходном порядке. Нули пропускаются, потому что условие требует положительные и отрицательные, а ноль не относится ни к тем, ни к другим.

## 3. Алгоритм в коде

```java
public static int[][] splitBySign(int[] numbers) {
    int positiveCount = 0;
    int negativeCount = 0;
    for (int i = 0; i < numbers.length; i++) {
        if (numbers[i] > 0) {
            positiveCount++;
        } else if (numbers[i] < 0) {
            negativeCount++;
        }
    }

    int[] positives = new int[positiveCount];
    int[] negatives = new int[negativeCount];
    int positiveIndex = 0;
    int negativeIndex = 0;
    for (int i = 0; i < numbers.length; i++) {
        if (numbers[i] > 0) {
            positives[positiveIndex] = numbers[i];
            positiveIndex++;
        } else if (numbers[i] < 0) {
            negatives[negativeIndex] = numbers[i];
            negativeIndex++;
        }
    }
    return new int[][] {positives, negatives};
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(n) |

**Обоснование.** Два последовательных цикла по n элементов, то есть O(n). Массивы `positives` и `negatives` вместе содержат не больше n элементов (нули в них не попадают), поэтому память O(n).
