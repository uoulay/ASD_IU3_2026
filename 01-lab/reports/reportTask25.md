## 1. Условие

Вход: массив из n целых чисел.
Выход: сумма всех элементов.

Ввод:
n
a1 a2 ... an

## 2. Идея решения

Один проход по массиву с накоплением суммы в переменной типа `long`: сумма до 10^5 чисел `int` может достигать порядка 2·10^14 и не поместилась бы в `int`.

## 3. Алгоритм в коде

```java
public static long sumAll(int[] numbers) {
    long sum = 0;
    for (int i = 0; i < numbers.length; i++) {
        sum = sum + numbers[i];
    }
    return sum;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(1) |

**Обоснование.** Цикл `for` делает ровно n итераций по одному сложению, итого O(n). Память: `sum` и счётчик, O(1).
