## 1. Условие

Вход: квадратная матрица n x n.
Выход: сумма элементов на главной диагонали.

Ввод:
n
дальше n строк по n чисел

## 2. Идея решения

Элементы главной диагонали квадратной матрицы стоят на позициях `matrix[i][i]`, поэтому обходить всю матрицу не нужно: достаточно одного цикла по `i` от 0 до n − 1.

## 3. Алгоритм в коде

```java
public static long sumMainDiagonal(int[][] matrix) {
    long sum = 0;
    for (int i = 0; i < matrix.length; i++) {
        sum = sum + matrix[i][i];
    }
    return sum;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(1) |

**Обоснование.** Цикл делает n итераций по одному сложению, остальные n² − n ячеек не просматриваются. Итого O(n) относительно размера стороны матрицы (или O(√N) относительно общего числа элементов N = n²). Память: `sum` и счётчик, O(1).
