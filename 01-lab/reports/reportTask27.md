## 1. Условие

Вход: массив из n целых чисел.
Выход: сумма квадратов всех элементов.

Ввод:
n
a1 a2 ... an

## 2. Идея решения

Один проход, на каждом шаге элемент приводится к `long` и возводится в квадрат. Приведение делается до умножения: квадрат `int` вроде 46341 · 46341 уже не помещается в `int`, и без приведения получилось бы неверное число. Сумма также хранится в `long`: диапазона `long` хватает для суммы квадратов при ограничениях условия.

## 3. Алгоритм в коде

```java
public static long sumOfSquares(int[] numbers) {
    long sum = 0;
    for (int i = 0; i < numbers.length; i++) {
        // Сначала привожу к long, иначе квадрат большого числа не влезет в int.
        long value = numbers[i];
        sum = sum + value * value;
    }
    return sum;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(1) |

**Обоснование.** Цикл `for` делает n итераций с одним умножением и одним сложением, то есть O(n). Память: `sum`, `value` и счётчик, O(1).

Входные данные записаны в формате, который читает `main` (первая строка — размеры, далее элементы). Ожидаемые ответы получены вручную до запуска программы, затем сверены с её выводом.

**Покрытие кода.** Единственный цикл выполняется всеми тестами. Тесты 4–6 проверяют, что приведение к `long` стоит в правильном месте.
