## 1. Условие

Вход: массив из n целых чисел. Все элементы различны.
Выход: второй по величине элемент массива.

Ввод:
n
a1 a2 ... an

## 2. Идея решения

Решение за один проход без сортировки. Сначала первые два элемента сравниваются между собой и определяют начальные `largest` и `second`. Затем для каждого следующего элемента: если он больше `largest`, прежний максимум становится вторым, а он сам — максимумом; иначе, если он больше `second`, он становится вторым. Все числа различны (условие), поэтому равенства не рассматриваются.

## 3. Алгоритм в коде

```java
public static int findSecondLargest(int[] numbers) {
    // Сначала сравниваю первые два числа, потом смотрю остальные.
    int largest;
    int second;
    if (numbers[0] > numbers[1]) {
        largest = numbers[0];
        second = numbers[1];
    } else {
        largest = numbers[1];
        second = numbers[0];
    }

    for (int i = 2; i < numbers.length; i++) {
        if (numbers[i] > largest) {
            second = largest;
            largest = numbers[i];
        } else if (numbers[i] > second) {
            second = numbers[i];
        }
    }
    return second;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(1) |

**Обоснование.** Один цикл `for` от 2 до n − 1, в теле не больше двух сравнений и двух присваиваний, это O(n). Память: `largest`, `second` и счётчик, то есть O(1).

## 5. Ручные тесты

Входные данные записаны в формате, который читает `main` (первая строка — размеры, далее элементы). Ожидаемые ответы получены вручную до запуска программы, затем сверены с её выводом.

| № | Ввод | Ожидаемый вывод | Что проверяет |
|--:|------|-----------------|---------------|
| 1 | `3`<br>`1 5 3` | `3` | новый элемент 3 встаёт между вторым и максимумом |
| 2 | `2`<br>`1 2` | `1` | минимальная длина, первый меньше второго |
| 3 | `2`<br>`2 1` | `1` | минимальная длина, первый больше второго |
| 4 | `4`<br>`1 2 3 4` | `3` | каждый новый элемент — новый максимум |
| 5 | `4`<br>`4 3 2 1` | `3` | остальные элементы меньше второго, ни одна ветка не срабатывает |
| 6 | `4`<br>`5 1 3 2` | `3` | 3 обновляет второй максимум, а 2 уже не обновляет |
| 7 | `3`<br>`-1 -5 -3` | `-3` | отрицательные числа |

**Покрытие кода.** Тесты 2 и 3 проходят обе ветки начального сравнения. Внутри цикла: ветка `> largest` — тест 4, ветка `> second` — тесты 1 и 6, случай «ни одна не сработала» — тест 5.
