## 1. Условие

Вход: массив из n целых чисел.
Выход: произведение всех элементов по модулю 10^9 + 7.

Ввод:
n
a1 a2 ... an

## 2. Идея решения

Произведение сотен чисел не поместится ни в какой тип, поэтому остаток берётся на каждом шаге: `(a · b) mod m = ((a mod m) · (b mod m)) mod m`. Промежуточный результат всегда меньше 10^9 + 7, а произведение двух таких чисел меньше 10^18 и помещается в `long`. В Java остаток от деления отрицательного числа отрицателен, поэтому к нему прибавляется модуль, и ответ всегда лежит в диапазоне от 0 до 10^9 + 6.

## 3. Алгоритм в коде

```java
private static final long MODULO = 1000000007L;

public static long productModulo(int[] numbers) {
    long product = 1;
    for (int i = 0; i < numbers.length; i++) {
        long current = numbers[i] % MODULO;
        // У отрицательного числа остаток в Java тоже отрицательный.
        if (current < 0) {
            current = current + MODULO;
        }
        product = (product * current) % MODULO;
    }
    return product;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(1) |

**Обоснование.** Цикл `for` делает n итераций, на каждой фиксированное число арифметических операций (два взятия остатка, одно умножение), это O(n). Память: `product`, `current` и счётчик, O(1).
