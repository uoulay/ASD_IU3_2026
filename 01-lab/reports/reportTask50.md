## 1. Условие

Вход: матрица n x m из целых чисел.
Выход: массив из m элементов — сумм столбцов.

Ввод:
n m
дальше n строк по m чисел

Вывод: суммы столбцов через пробел.

## 2. Идея решения

Внешний цикл идёт по столбцам, внутренний — по строкам, и суммирует элементы одного столбца. Число столбцов берётся из первой строки (`matrix[0].length`), все строки одинаковой длины. Результат — массив из m элементов.

## 3. Алгоритм в коде

```java
public static long[] sumColumns(int[][] matrix) {
    int rows = matrix.length;
    int columns = matrix[0].length;
    long[] sums = new long[columns];
    for (int column = 0; column < columns; column++) {
        long sum = 0;
        for (int row = 0; row < rows; row++) {
            sum = sum + matrix[row][column];
        }
        sums[column] = sum;
    }
    return sums;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n · m) |
| Дополнительная память | O(m) |

**Обоснование.** Внешний цикл делает m итераций, внутренний — n, каждая ячейка посещается один раз: O(n · m). Дополнительная память — массив `sums` из m элементов, O(m).
