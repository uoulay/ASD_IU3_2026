## 1. Условие

Вход: массив из n целых чисел.
Выход: сумма элементов с чётными индексами (0, 2, 4, ...).

Ввод:
n
a1 a2 ... an

## 2. Идея решения

Индексы 0, 2, 4, … перебираются циклом с шагом 2, поэтому нечётные позиции вообще не просматриваются. Сумма копится в переменной `long`, потому что сумма до 10^5 чисел типа `int` может не поместиться в `int`.

## 3. Алгоритм в коде

```java
public static long sumEvenIndexes(int[] numbers) {
    // Сумма может не влезть в int, поэтому считаю в long.
    long sum = 0;
    for (int i = 0; i < numbers.length; i = i + 2) {
        sum = sum + numbers[i];
    }
    return sum;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(1) |

**Обоснование.** Цикл `for (int i = 0; i < numbers.length; i = i + 2)` делает ⌈n/2⌉ итераций, это O(n). Память: `sum` и `i`, то есть O(1).

Входные данные записаны в формате, который читает `main` (первая строка — размеры, далее элементы). Ожидаемые ответы получены вручную до запуска программы, затем сверены с её выводом.
