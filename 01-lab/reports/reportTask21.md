## 1. Условие

Вход: массив из n целых чисел и число k (1 <= k <= n).
Выход: k-й наименьший элемент.
По условию массив нужно отсортировать и взять элемент с индексом k - 1.

Ввод:
n k
a1 a2 ... an

## 2. Идея решения

По условию массив нужно отсортировать и взять элемент с индексом k − 1: после сортировки по неубыванию на этом месте стоит k-й наименьший. Для сортировки используется стандартный `Arrays.sort`, написание собственной сортировки в условии не требуется. Равные числа занимают отдельные места, то есть в массиве `5 5 1` второй наименьший равен 5.

## 3. Алгоритм в коде

```java
public static int findKthSmallest(int[] numbers, int k) {
    // По условию достаточно отсортировать и взять нужный по счёту элемент.
    Arrays.sort(numbers);
    return numbers[k - 1];
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n log n) |
| Дополнительная память | O(log n), в худшем случае до O(n) |

**Обоснование.** Вызов `Arrays.sort(int[])` выполняется за O(n log n) (быстрая сортировка с двумя опорными элементами, в JDK 14+ с защитой от худшего случая). Обращение `numbers[k - 1]` стоит O(1). Итого O(n log n). Память: сортировка идёт на месте, но использует стек рекурсии O(log n), а при слиянии уже упорядоченных участков может создавать временный массив до O(n).

Входные данные записаны в формате, который читает `main` (первая строка — размеры, далее элементы). Ожидаемые ответы получены вручную до запуска программы, затем сверены с её выводом.

| № | Ввод | Ожидаемый вывод | Что проверяет |

| 6 | `4 2`<br>`-1 -3 0 -3` | `-3` | отрицательные числа и повтор |
| 7 | `2 2`<br>`1 2` | `2` | k = n при n = 2 |
| 8 | `3 2`<br>`1 2 3` | `2` | уже отсортированный массив |

**Покрытие кода.** В методе всего две строки, обе выполняются любым тестом. Граничные значения k = 1 и k = n проверены тестами 3, 4, 5, 7.
