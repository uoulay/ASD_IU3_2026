## 1. Условие

Вход: два массива одинаковой длины n.
Выход: скалярное произведение.

Ввод:
n
a1 a2 ... an
b1 b2 ... bn

## 2. Идея решения

Скалярное произведение — сумма попарных произведений `a[i] · b[i]`. Проход один, оба массива просматриваются синхронно по общему индексу. Приведение к `long` стоит перед умножением: `(long) first[i] * second[i]`, иначе произведение двух `int` переполнится ещё до сложения.

## 3. Алгоритм в коде

```java
public static long scalarProduct(int[] first, int[] second) {
    long sum = 0;
    for (int i = 0; i < first.length; i++) {
        sum = sum + (long) first[i] * second[i];
    }
    return sum;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(1) |

**Обоснование.** Цикл `for` делает n итераций, на каждой одно умножение и одно сложение, итого O(n). Дополнительно используются `sum` и счётчик, то есть O(1). Входные массивы длины n не считаются дополнительной памятью.
