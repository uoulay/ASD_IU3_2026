## 1. Условие

Вход: массив из n целых чисел и число x.
Выход: индекс первого элемента, равного x. Если такого нет — -1.

Ввод:
n x
a1 a2 ... an

## 2. Идея решения

Массив просматривается слева направо. Как только найден элемент, равный `x`, его индекс возвращается сразу, дальше идти не нужно, потому что нужен именно первый. Если цикл закончился без совпадений, возвращается `-1`. Дополнительные структуры не нужны, достаточно массива `int[]`.

## 3. Алгоритм в коде

```java
public static int findFirstIndex(int[] numbers, int target) {
    for (int i = 0; i < numbers.length; i++) {
        if (numbers[i] == target) {
            return i;
        }
    }
    return -1;
}
```

## 4. Анализ асимптотики

| | Оценка |
|---|---|
| Время (худший случай) | O(n) |
| Дополнительная память | O(1) |

**Обоснование.** В худшем случае (число стоит в конце или отсутствует) цикл `for` проходит все n элементов, каждый раз выполняя одно сравнение, это O(n). В лучшем случае возврат происходит на первой итерации, но оценка делается по худшему. Используются только переменная цикла и `target`, то есть O(1).
